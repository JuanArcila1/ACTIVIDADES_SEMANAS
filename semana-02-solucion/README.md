# Semana 02 — Widgets y Layout

**Aprendiz:** Juan Manuel Arcila Cifuentes
**Bootcamp:** Flutter — `bc-flutter`
**Dominio asignado:** Empresa de importación
**Entidades:** suppliers, products, shipments, customs

## Objetivo
Crear una pantalla Flutter con buscador, lista y datos del dominio.

## Adaptación al dominio
La implementación usa proveedores, productos, envíos y aduanas como entidades del negocio de importación.

## Nota
Esta entrega fue preparada a partir de los requisitos públicos de la semana correspondiente del repositorio `ergrato-dev/bc-flutter`. El repositorio remoto no pudo clonarse desde el entorno de ejecución, por lo que estos ZIP contienen una implementación independiente y funcional del entregable, no una copia binaria del starter.

Abrir la carpeta como proyecto Flutter y ejecutar `flutter pub get` / `flutter run`.
